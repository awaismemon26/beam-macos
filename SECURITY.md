# Security policy

Beam runs with Accessibility access, so security reports are taken seriously.

Please **don't open a public issue** for a vulnerability. Instead, report it privately through
[GitHub's private vulnerability reporting](https://github.com/awaismemon26/beam/security/advisories/new).
You'll get a reply within a few days, and a fix will be released as soon as possible.

Only the latest release is supported with security fixes.
